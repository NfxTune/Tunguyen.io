1. Kết nối GitHub

Repo: nguyen123tu/nguyen123tu.github.io · Token chỉ lưu trong trình duyệt này, không nằm trong code.

Cách tạo token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → chọn đúng repo nguyen123tu.github.io.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Đặt hạn dùng (ví dụ 90 ngày), tạo rồi dán token vào ô trên.
